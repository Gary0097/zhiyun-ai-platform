# 客户演示剧本与验收清单（2026-08-26）

> 适用：制造云 AI-OS 演示环境（`http://127.0.0.1:8088`，QwenPaw 2.1.0，五大 Studio 0.2.2）。
> 目标：客户自带 Excel/CSV 数据，在应用内直接导入并得到结构化分析结果。

## 一、演示前准备（演示方）

1. 启动：仓库根目录 `start-ai-os.cmd`（或 `node apps/qwenpaw-embedded/scripts/start.mjs`），等待 `http://127.0.0.1:8088/api/version` 返回 `2.1.0`。
2. 登录账号：`admin` / `ZhizaoYun@2026`。
3. 备用样例：`docs/qa/demo-data/`（每应用一个目录，表头与界面列名完全一致；客户无自带数据时使用）。
4. 首页加载约 5-10 秒后进入应用（从侧边栏「应用」进入为推荐路径）。
5. 演示机需能访问 8088；如需实时 Agent 对话，需先配置可达的模型 provider（默认本地模型当前不可达，剧本已绕开）。

## 二、标准演示动线（每个应用约 3 分钟）

以「智能销售中心」为例：

1. 侧边栏「应用」→ 打开「智能销售中心」。
2. 左侧选「销售BI分析」。
3. 点击 **下载导入模板** → 得到 `销售BI分析.csv`（表头与界面一致）。
4. 打开模板填入客户真实数据（或直接使用备用样例）。
5. 点击 **导入 Excel/CSV** 选择文件 → 出现绿色「已导入 xxx.csv · N 行」标签，表格填充、可继续手工修改。
6. 点击 **生成销售BI** → KPI 卡片（营收/销量/订单数/客单价）、月度趋势、Top 排名立即生成，带方法标签与 Trace。
7. 在审阅条输入具名审阅人 → **接受** → **导出**；演示 **交给 Agent** 将结果带入应用内 Agent 抽屉。
8. 切换其他模块（客户价值分层 / 销售业绩统计）重复"导入 → 运行 → 审阅"。

其余应用同构：

| 应用 | 演示模块（可导入） | 附加演示（示例按钮） |
| --- | --- | --- |
| 智能销售中心 | 销售BI分析、客户价值分层、销售业绩统计 | — |
| 智能财务中心 | 报销审核、财务看板 | 成本预测（一键填入示例） |
| 智能人力中心 | 权限建议、通讯录协作、员工关怀、人力分析 | 审批路径（一键填入示例） |
| 智能供应中心 | 供应商评估、智能补货、风险监控 | — |
| 智能售后服务中心 | 知识库构建 | 咨询应答/意图识别（载入示例文本）、售后工单（一键填入示例） |

## 三、数据中心与 Data Studio 动线（可选，10 分钟）

1. 打开「统一数据中心」：演示 Excel 导入 → 数据环境（演示 Demo / 正式 Live）切换 → 来源筛选与批次。
2. 打开「企业数据分析中心」：基于数据中心订单的看板、交付风险预警、趋势（真实数据路径演示）。

## 四、验收清单（客户逐项确认）

| # | 验收项 | 通过标准 |
| --- | --- | --- |
| 1 | 登录 | admin 登录成功，进入工作台 |
| 2 | 应用打开 | 五大 Studio + 数据中心 + Data Studio 全部打开为结构化界面（无裸 JSON） |
| 3 | 模板下载 | 每个可导入模块都能下载表头一致的 CSV 模板 |
| 4 | 直接导入 | 客户自带 Excel/CSV 导入后表格正确填充，显示来源标签（文件名+行数） |
| 5 | 错误提示 | 表头不匹配时明确列出文件表头与本表需要的列 |
| 6 | 运行结果 | 每个模块运行后 KPI/明细非空，带方法标签与数据来源 |
| 7 | 审阅闭环 | 具名审阅人接受/驳回/导出状态正确联动 |
| 8 | Agent 抽屉 | 应用内"问 Agent"抽屉可打开，快捷指令生成工件卡片（本地执行，不依赖外部模型） |
| 9 | 稳定性 | 全程无报错弹窗；页面 2 秒内可交互 |

## 五、已知限制（向客户如实说明）

1. 模型 provider 未配置可达实例：实时流式 Agent 对话暂不可用（应用内 Agent 抽屉的模块执行流不受影响）。
2. 宿主新手引导弹层每次进入应用出现一次，可手动关闭。
3. 导入为"填入输入表格即析"的演示口径；统一数据库持久化导入（数据中心）为下一阶段能力。
4. 首页首次加载约 5-10 秒（应用插件注册）。
