# 启动品牌资源处理性能（#154）

2026-09-15，Windows 10 专业版 10.0.19045，Node.js 24.15.0，实际 QwenPaw 2.2.1 控制台资源。

本轮针对重复启动时重新生成 Brotli/gzip 的开销；不改运行时、认证、端口检查或插件安装。
同一隔离安装资源目录，交替运行发布版和优化版 `patch-console-ui.mjs --console-dir <console>`，用 PowerShell Stopwatch 计时。每轮命令均成功退出，输出重定向到日志。

| 轮次 | 发布版 | 优化版 |
| --- | ---: | ---: |
| 1 | 14.462 秒 | 3.201 秒 |
| 2 | 13.363 秒 | 2.836 秒 |

平均 13.913 秒降至 3.019 秒，减少约 78%，本机该阶段每次节省约 10.9 秒。
这是已品牌化资源的重复启动阶段计时，不是从双击到页面可用的总时间，也不包含首次解压或安装依赖。
其他 Win10 机器的 CPU、磁盘、杀毒扫描和网络状态可能改变结果；不据此承诺整个应用 3 秒启动。

实现：逐字节比较原文件，内容相同不重复写入；压缩副本必须解压后与目标内容完全一致才能复用，缺失、损坏或过期时重建。仅在计算文件名哈希时移除文档版本参数，引用改写保留它，避免每次先移除后恢复造成重复压缩。需要写入时继续使用独立临时文件原子替换，不写穿 uv 缓存硬链接。

验证：品牌化测试 96 项通过，包括未变化入口/压缩文件不写入、损坏 Brotli、可解压但过期 gzip、缺失副本重建，以及已有关于链接、缓存更新和品牌回归；`node scripts/verify-release.mjs` 完整通过。

Windows/Linux 使用同一 Node 逻辑；Windows 完整门禁已运行，本轮没有 Linux 实机性能数据。没有改动已安装服务或用户工作区。
回退时撤销本次脚本变更并重新运行品牌补丁即可，不涉及数据库或账号迁移。
