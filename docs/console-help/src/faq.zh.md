# 常见问题

## 默认账号密码是什么？

安装包没有预设账号密码。全新单机安装首次自行注册；Hub 首个注册账号成为管理员。升级保留已有账号，单机与 Hub 不共用账号。

## 点击桌面快捷方式没有反应？

后台初始化可能需要数分钟。检查托盘运行状态与安装目录 launcher-service.log，避免连续双击。服务就绪后访问 http://127.0.0.1:8088/。若日志出现错误，记录具体阶段再排查，不要删除工作区。

## 如何安装或升级？

按[快速开始](./quickstart)使用本发行版入口。升级需获取新发行版安装包或经审查的项目版本，备份数据、停止服务后按发布说明更新。单纯重启旧版本启动器不会下载新的发行版源码；不要使用未锁版本的 pip 或 latest 镜像替代本项目更新。

## Linux 可以用 Windows 离线包吗？

不能。两者的 Node、Python 和依赖缓存不同。Linux 联网安装先运行 setup-ai-os.sh，再运行 start-ai-os.sh；Hub 另见[部署指引](./hub)。

## 数据在哪里？

默认位于安装目录 apps/zhizaoyunAIOS/workspace。账号与凭据默认在其中的 secret，Hub 数据在 hub 子目录。自定义目录按实际配置备份，详见[配置与工作目录](./config)。

## 模型无法对话或返回 401？

先确认已选择模型、供应商地址和模型名正确，凭据有效且该供应商账户有相应权限。不要把控制台登录密码当作模型 API Key。网络超时需要结合日志判断，不能仅凭超时就修改系统网络配置。

本地模型需要先准备模型和依赖；上下文大小、工具调用支持及硬件资源也会影响结果。技术参数见[模型参考](./models)。

## 管理员录入 Key 后员工能直接用吗？

当前原生 Hub 凭据仅作用于同一账号的个人租户，不会自动共享。集中供给仍待实现和验收，详见[Hub 部署](./hub)。

## 端口 8088 被占用怎么办？

由管理员确认占用进程是否属于当前安装。不要结束不明进程或随意修改系统端口保留范围。单机启动器使用 8088，Hub 使用 8000；收集错误日志后通过[企业内支持](./community)处理。

## 定时任务没有执行或消息没有送达？

先确认任务已启用，运行该任务的单机服务或 Hub 租户正在运行，再核对计划时间、时区及下一次执行时间。使用控制台的立即运行功能检查错误：任务依赖的模型、凭据和工具必须在同一智能体下可用。

若任务执行成功但没有收到消息，检查目标频道是否启用、收件人或会话标识是否正确，以及机器人权限和频道日志。避免连续重试可能产生重复发送的任务。记录任务标识、执行时间与脱敏错误信息，详见[定时任务](./cron)和[频道](./channels)。

## 如何反馈问题？

提供系统版本、安装方式、复现步骤和脱敏日志。删除密码、API Key、令牌及客户内容后再提交；详细渠道见[问题反馈](./community)。
