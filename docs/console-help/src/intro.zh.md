# 项目介绍

智造云 AIOS 2.2.1 是基于 QwenPaw 2.2.1 与 QwenPaw Hub 的品牌发行版。智造云提供安装与启动入口、品牌界面和发行版使用指引；智能体运行时与原生认证由上游提供。

## 从这里开始

1. 按[快速开始](./quickstart)安装并启动。
2. 首次打开控制台自行注册账号；安装包没有预设账号密码。
3. 配置模型供应商或本地模型，完成一次真实对话。
4. 团队部署使用[Hub 入口](./hub)，不要把单机端口直接作为团队入口。

| 范围 | 本发行版说明 |
| --- | --- |
| 单机 | 本机控制台，端口 8088，原生认证 |
| Hub | 多用户入口，端口 8000，每用户独立运行环境 |
| 运行时 | 锁定 QwenPaw 2.2.1，不修改内核 |
| 业务应用 | 不捆绑 Creator、Studio 等业务应用，独立交付并另行验收 |
| 模型 | 自行配置；安装包不含 API Key 或已下载的模型权重 |

云端模型请求会发送给所选供应商。本地模型也需先准备依赖和权重，离线安装不代表无需配置即可离线对话。

## 技术来源

QwenPaw、AgentScope、ReMe 等表示各自的上游项目，不代表智造云自研。帮助中心将发行版指引与上游技术参考区分；真实命令、模型名称和 API 保持原样。技术参考不代表本发行版对每项功能已验收，数据位置以[配置与工作目录](./config)为准。
