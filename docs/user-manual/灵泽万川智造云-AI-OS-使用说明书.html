智造云 AIOS 2.2.0 使用说明

当前为候选验收版本。正式发布前，请查看 docs/operations/RELEASE-2.2.0-ACCEPTANCE.md 中的已验证项目与剩余限制。

1. 产品与运行模式

智造云 AIOS 使用 QwenPaw 2.2.0 原生运行时和 Hub，提供品牌界面、安装程序及启动入口。本发行版不捆绑业务 PawApp 或 Studio 应用；旧业务应用的历史数据不会因架构调整而自动删除。

模式用途入口地址
单机个人工作空间start-ai-os.cmd / start-ai-os.shhttp://127.0.0.1:8088
Hub团队账号与隔离运行环境start-hub.cmd / start-hub.sh本机首次配置后开放局域网 8000 端口

对话、技能、模型配置和工具连接使用原生控制台。云模型会把请求内容发送给所选供应商；本地模型也不代表联网工具、频道或连接器不会向外发送数据。

2. Windows 安装与启动

使用经过校验的 2.2.0 安装包，运行图形安装程序，选择安装目录和桌面快捷方式选项。安装完成后点击“打开智造云 AIOS”，或使用桌面入口。首次启动需要加载运行环境，可能耗时数分钟。

源码部署使用仓库根目录的 setup-ai-os.ps1，再运行 start-ai-os.cmd。离线 ZIP 必须完整解压后使用，不能只复制启动文件。离线包中的缓存用于安装 Python 依赖，不包含模型服务账号或云模型额度。

单机首次访问 8088 页面时创建个人账号。没有预置的生产用户名或默认密码，单机模式不开放第二个账号注册。多人使用请部署 Hub。

3. Windows Hub

运行 start-hub.cmd，按 Windows 提示授予管理员权限。Windows Local 隔离运行环境需要此权限；仅打开登录页不能证明用户运行环境可用。

首次启动仅监听 127.0.0.1:8000。在本机注册首个管理员后，停止并重新启动 Hub，服务才开放局域网监听。管理员可创建员工账号，也可按组织要求修改 hub.yaml 的注册设置后重启。

同事使用服务器的局域网地址访问 8000 端口。自定义域名应在 hub.yaml 中配置 public_base_url，并由受信任的反向代理提供 HTTPS。派生的 hub.runtime.yaml 由启动器生成。

4. Ubuntu Hub

需要 Node.js 20+、可用的 Python 运行环境引导条件，以及 Bubblewrap。运行 bash start-hub.sh，首次账号初始化顺序与 Windows 相同。

Ubuntu 24.04 WSL2 验收环境已验证 Hub 启动和双向工作区文件隔离。普通 Docker 容器可能不允许 Bubblewrap 所需的命名空间；不要为了启动成功而关闭隔离保护。Windows 离线包的二进制缓存不能当作 Ubuntu 离线依赖包使用。

5. 模型与凭据

在控制台配置所需模型供应商、模型名称和凭据，再进行实际对话验证。模型未配置、凭据无效或网络不可达时，应先处理错误，不以固定文本代替真实模型结果。

原生 Hub 的凭据保险库按登录账号的个人租户加密保存凭据，并注入同一租户的运行环境。管理员录入的凭据不会自动共享给员工。产品要求的“管理员统一供给、员工零接触密钥”尚未完成验收，跟踪 #138；不能把个人租户配置当作全员供给方案。

6. 数据与备份

停止对应服务后，整体备份安装目录中的 apps/zhizaoyunAIOS/workspace，以及存在时的 apps/zhizaoyunAIOS/workspace.secret。Hub 数据位于工作区的 hub 子目录，必须连同数据库、secrets、用户运行环境数据一起备份。不要只复制数据库而遗漏加密密钥。

升级前还应备份 hub.yaml。旧版业务应用曾使用的其他数据目录也需要保留；新版不负责迁移那些独立应用的数据。

不要将工作区、备份、密钥或真实账号配置加入 Git 或安装包。

7. 升级与卸载

覆盖升级时选择原安装目录。安装器保留已有工作区和 hub.yaml，只更新程序文件；正式使用前仍应保留可恢复的完整备份。

图形卸载程序按安装文件清单移除程序、已记录的运行时文件及本安装的快捷方式。工作区、账号、Hub 配置和未知文件保留在原目录。卸载不等于清除个人数据；保留的数据仍需由你妥善管理。

候选包的完整安装、覆盖升级及卸载流程仍以验收记录为准，不能用专项测试代替整包验证。

8. 常见问题

8088 或 8000 端口被占用

确认是否已有智造云实例在运行。不同安装目录的实例不能同时占用相同端口；不要直接结束不明进程。

Hub 页面能打开，但运行环境启动失败

Windows 检查管理员权限；Ubuntu 检查 Bubblewrap 与宿主机命名空间支持。查看该运行环境的日志，登录成功与运行环境就绪是两个不同阶段。

忘记单机密码

先停止单机服务并备份数据，确认当前实例实际使用的 secret 目录，再按原生说明处理其中的 auth.json 并重新注册。此操作重置本地账号，不能用来替代 Hub 账号管理，也不应删除整个工作区。

界面未更新或显示异常

确认当前访问的是正确安装实例，重启服务并刷新页面。运行 diagnose-ai-os.cmd / diagnose-ai-os.sh 获取诊断信息。反馈问题时记录系统、窗口尺寸和复现步骤，日志应先移除敏感信息。

安装失败

查看安装目录中的 install-wizard.log、install-runtime.log 或 install-log.txt（以实际安装方式为准）。修复原因后重试；不要删除工作区来尝试修复依赖。
