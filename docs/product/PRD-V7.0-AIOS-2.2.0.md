# 智造云 AIOS 2.2.0 产品需求文档（PRD V7.0）

> 状态：已定稿（产品决策 2026-09-04）
> 取代：`AI-OS-PRD-V6.4-QwenPaw-PawApps.md`（归档于 `docs/product/archive/`）

---

## 1. 产品定义

**智造云 AIOS 2.2.0** 是基于 **原版 QwenPaw 2.2.0 + QwenPaw Hub** 构建的企业级
智能体操作系统发行版，以智造云品牌与开箱即用的部署体验交付：

| 维度 | 定义 |
| --- | --- |
| 内核 | 原版 QwenPaw 2.2.0（Agent 运行时 / 桌面控制台 / Agent 容器，不做内核改动） |
| 多用户 | 原版 QwenPaw Hub（局域网多用户、按用户隔离的运行环境） |
| 品牌 | 控制台与 Hub 界面全面智造云风格（“智造云 AIOS”标识、齿轮 Logo、品牌色） |
| 登录 | QwenPaw 2.2.0 原生认证（单机）+ Hub 账号体系（多用户），不使用自定义登录插件 |
| 模型账号 | 集中于 Hub 服务器端配置（凭据保险库 → 按用户环境注入），员工零接触 API Key |
| 应用 | **无捆绑业务应用**；应用体系与系统解耦，另行独立交付（见第 6 节） |

一句话：**用户拿到的是一台"智造云牌"的原版 QwenPaw 智能体计算机——单机即插即用，
连上 Hub 即成团队版，模型账号由管理员统一供给。**

## 2. 部署形态

### 2.1 单机形态（端口 8088）

- 启动：`start-ai-os.cmd` / `.sh`（或桌面快捷方式 / 托盘启动器）
- 登录：控制台原生登录（`QWENPAW_AUTH_ENABLED=true`）；首个用户在控制台注册
- 密码找回：删除 `<secret>/auth.json` 后重新注册（上游文档化行为）
- 适用：个人/单台设备使用

### 2.2 Hub 形态（端口 8000，多用户推荐）

- 启动：`start-hub.cmd` / `.sh`（首次自动安装 Hub 运行环境）
- 登录：Hub 账号体系；首个注册账号为管理员，建议随后关闭自助注册
- 用户隔离：每用户独立运行环境（工作区、凭据、进程/容器隔离）
- 模型账号：管理员在 Hub「凭据管理」集中录入供应商 Key（加密保险库存储，
  启动用户环境时注入为环境变量）；员工登录即用，全程不接触 Key
- 数据位置：`<工作目录>/hub/`（备份须整体备份含 secrets/）

## 3. 系统能力（继承 QwenPaw 2.2.0 原生能力）

智能体对话与三层记忆（ReMe 自进化知识库）、Skills 体系、MCP/ACP/驱动连接、
频道（钉钉/飞书/微信/Discord 等）、定时任务、统一模型路由（30+ 供应商与
本地模型）、文件工作区、检查点、Token 消耗观测、安全治理（沙箱/Tool Guard/
Skill Scanner）。以上能力**全部使用上游原生实现**，本仓库不 fork 内核行为。

## 4. 本仓库范围（In Scope）

1. 启动器与安装脚本（单机 + Hub，Windows/Linux 双平台）
2. 品牌化（`patch-console-ui.mjs`：控制台/Hub 文案与 Logo 替换为智造云 AIOS；
   `branding/` 资产）
3. 运行时版本锁（`qwenpaw.lock.json` = 2.2.0）与供给（setup-ai-os / setup-hub）
4. 文档（PRD、使用说明、部署指南）
5. 发布门禁与打包脚本（安装包构建暂缓，按需恢复）

## 5. 明确非目标（Out of Scope）

- 不修改 QwenPaw 内核行为（上游升级随锁文件整体跟进）
- 不在本仓库捆绑、vendor 任何业务应用或插件
- 不自建登录/权限系统（单机用原生认证，多用户用 Hub）
- 不恢复企业服务、8390 端口或任何第二应用服务

## 6. 应用体系解耦（原 19 个业务应用的去向）

V6.4 时代的 19 个业务 PawApp（数据中心/订单/供应链/销售/财务/人力/售后/
集成/畅捷通/Creator 三件套/Agent 看板等）已全部从本发行版剔除：

- 它们将继续以**独立应用**形态存在与演进，各自拥有仓库、版本与发布节奏；
- 未来以"可选加装"方式回归（如独立安装包、应用市场分发），加装后运行于
  智造云 AIOS 的 QwenPaw 插件体系之上；
- 剔除期间其业务数据（Workspace、Studio 数据库等）不被删除或迁移，保留在
  既有安装目录，待对应应用回归后继续使用。

## 7. 验收口径

- 单机：`start-ai-os.cmd` → 控制台原生登录可用 → 对话/技能/模型配置正常 →
  界面呈现智造云 AIOS 品牌
- Hub：`start-hub.cmd` → 管理员注册 → 凭据集中录入 → 员工账号登录并直接
  使用已注入的模型 → 各用户环境互相隔离
- 门禁：`node scripts/verify-release.mjs` 通过（版本锁 / 双平台入口 /
  原生登录启用 / 品牌化 / 无捆绑应用残留）
- 禁止以演示数据冒充真实能力；空态保持可见的空

## 8. 版本与升级

- 系统版本与运行时版本对齐：**2.2.0**
- 上游 QwenPaw 升级 = 修改 `qwenpaw.lock.json` + 同步门禁断言 + 实机验证
  （健康检查与能力回归），以 PR 评审合并
- 安装包构建在本版本定稿后按需恢复（`make-release-package.mjs` /
  `make-exe-installer.mjs` 已适配无 PawApp 形态）
