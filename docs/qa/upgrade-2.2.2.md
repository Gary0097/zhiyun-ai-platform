# QwenPaw 2.2.2 办公分支升级验收

2026-10-19，Issue #156。用户明确授权升级和合并；目标分支 `aios-office`。

## 来源与变更

- 官方发布：https://github.com/agentscope-ai/QwenPaw/releases/tag/v2.2.2
- 精确提交：`5c56644a6e130762a236f8c946103e95a0a1eec8`。
- PyPI 官方 wheel SHA-256：`fcc442bd4ca1b426104f16d3aff4e6c1da90a057a58f2b509d9497d2938afd4d`，下载后实际验证。
- 同步运行时锁、安装器版本、启动提示、门禁和当前帮助文档。保持原运行目录、原生认证、办公技能和 LibreOffice 26.8.1；不修改上游内核。
- 官方包要求 `onnxruntime<1.24`；原 Windows 固定 1.31.0 与之冲突。改为 1.23.2，固定完整 44 项办公依赖闭包；通用 requirements 同步上限，避免 Linux 启动供给重新装入不兼容的新版本。
- 新控制台构建重命名了文件预览函数的局部变量，并拆出了默认语言变量。品牌补丁改为匹配稳定的函数/表达式，继续保留特殊文件名编码修复及用户语言偏好；更新补丁签名使旧标记不会跳过新版适配。

## 实测

Windows 主机、全新隔离目录与 venv，安装 `qwenpaw[hub]==2.2.2` 和办公固定依赖：

- `uv pip check`：268 个已安装包全部兼容。
- 真实官方 Console 资源打补丁及 `--check` 通过；fixture 使用 2.2.2 的语言声明和文件预览代码，覆盖默认中文、下载编码、幂等、资源引用、缓存及品牌保护。
- 完整 `node scripts/verify-release.mjs` 通过（包含 Windows 安装器、恢复与数据保护回归）。
- Word、Excel、PPT、PDF、中文 OCR、文件/数据/图片、Word/PPT 转 PDF 与 Excel 公式重算，七组真实合成文件测试通过。
- 独立端口 18088/18000：单机原生认证、账号跨重启保留、匿名 token 校验 401、中文/空格/#/%20 文件下载、Hub 首管理员初始化、管理员数据库安全绑定查询和 Hub 重启通过。
- 最近一次原生运行时就绪时间：单机 4.563/4.781 秒，Hub 3.844/3.828 秒。这些是隔离端口的原生服务计时，不包含桌面启动器或完整安装流程。
- 将旧 2.2.1 合成验收账号与 `.master_key` 一起复制到临时目录，新运行时可以读取，两个文件哈希不变；不读取或迁移生产密钥。

可重复的运行时检查：在专用隔离发行目录创建 `.synthetic-runtime-acceptance`，内容为 `synthetic-only`，再运行 `scripts/test-runtime-upgrade.py --root <隔离目录> --output <结果目录>`。脚本只创建合成账号，拒绝占用中的端口，仅停止自己启动的进程树。

## 范围与限制

本次升级和合并办公分支源码，不重发已有 `aios-office-v1.6.0` 资产，不升级 H 盘现有平台，不改变生产账号或模型配置。旧 Release 仍为 2.2.1；新的 Windows 完整安装包必须重新构建并验收后另行发布。

没有执行 Linux 实机安装、Hub 成员隔离运行环境/组织模型网关完整调用、真实模型对话、新增终端/PawPort 功能或 GUI 人工视觉验收。Linux 由 GitHub Ubuntu 发布门禁验证源码与入口；不能把上游发布说明当作这些项目已验收的证明。

## 升级与回退

实际部署前完整备份安装目录，尤其 `workspace/`、`workspace/secret/` 和 Hub 数据库及 secrets；先停服务，再用新版本锁准备独立运行环境，验证后切换。回退恢复旧程序与旧 venv，保留升级后产生的新文件；数据库可能经历上游迁移，须使用升级前的数据库备份，不能只降级 Python 包。不得单独恢复 auth.json 而丢失对应主密钥。
