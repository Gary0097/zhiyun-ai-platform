## 二、结论摘要

1. **不存在「功能只有 JSON 数组」的情况。** 五个 Studio 的 18 个模块全部渲染为结构化 GUI：顶部工具条 + 左侧功能导航 + 可编辑输入区（文本 / 表格 / 表单）+ 结果面板（KPI 卡片 + 明细表格/应答/趋势 + 方法标签 + Trace + 接受/驳回/导出/交给 Agent）。
2. **18/18 模块一键导入示例数据后均能运行出真实后端结果**，结果区非空、非「暂无分析结果」，且不包含 `"key":` 形式的原始 JSON 泄露。
3. **五个 Studio 右上角均存在「问 Agent」入口**，可打开智能体抽屉。
4. **Data Studio 渲染真实经营看板**（订单总数 100、高风险 18、风险率 38%、逾期 39、平均进度 69.7%，以及可审阅订单表 + 刷新数据 + 保存为待审阅工件）。
5. **全部 16 个注册插件均带 `frontend_entry` 且为 React 组件化前端**（`useState` / `createElement` / `Card` / `Button` / `Table`），无「撒 JSON」应用。`/` 根路径返回 QwenPaw Console HTML 前端，而非 JSON。

> 第二迭代复核（重要，替代本节旧结论）：用户反馈「系统应用无 GUI」属实并已定位——三个系统应用在 `app_catalog.json` 的 `route` 写成短名（`/apps/data-core` 等），与插件 `entry_page`/`registerRoutes` 的完整路由（`/apps/zhiyun-data-core` 等）不一致，导致从「应用中心」点「打开」落回「应用」列表。已改为完整路由并验证直达真实面板（数据核心 body 1249→2089，出现「统一数据中心 / 数据预览 / 订单明细」；应用中心命中 4 项；审计中心显示「审计链完整性已验证」+ Tool 审计表）。同时补充登录与权限（默认 `admin` / `ZhizaoYun@2026`）。其余业务 Studio 为真实结构化 GUI，具备一键导入示例数据 + 可运行 + 可审阅结果。

## 七、回归结论

- 18/18 模块通过；5 个 Studio 的 Agent 对话框通过；Data Studio 底座通过；全部 16 个注册插件均为组件化前端。
