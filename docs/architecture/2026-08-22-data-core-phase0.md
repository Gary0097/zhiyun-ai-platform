# Data Core Phase 0

## 决策

Data Core 是 AI-OS 系统插件，不作为独立桌面应用。它与 QwenPaw 使用同一进程和鉴权链路，不启动 8390 或其他用户可见端口。所有 PawApp 通过同源 API 使用共享数据，禁止直接修改 SQLite 文件。

## 数据模型

- `data_schemas` 与 `schema_fields` 保存用户可调整的字段定义。
- `data_batches` 记录真实导入或 AI 模拟数据的来源、数量和状态。
- `data_records` 以稳定记录 ID、批次 ID、来源类型和 JSON 数据保存业务记录。
- SQLite 作为本地第一阶段实现；API 保持数据库实现无关，后续可以增加 PostgreSQL 适配器。

## 可恢复性

导入和模拟数据必须先创建批次，再在同一事务写入记录。撤销只删除指定批次的数据并保留批次审计状态，不能影响其他真实或模拟数据。

## Schema 规则

用户字段使用稳定英文标识和可修改显示名称。第一阶段允许新增、修改显示名称和停用字段，不允许重命名稳定标识，以免破坏已保存记录和跨应用契约。

## Excel 边界

Data Core 接收标准行数据、字段映射和原始文件名，执行预览校验与事务写入。Excel/CSV 文件解析与工作表交互属于 Data Studio UI；这种划分避免 Data Core 绑定具体前端库，同时保证所有应用共用相同校验和批次撤销逻辑。
