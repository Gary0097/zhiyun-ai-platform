# 办公技能 · 制作内容

本技能是办公内容生产的**总编排**：先定策略与结构，再组织素材，最后调用
对应技能成稿（word 文档 / ppt 汇报 / excel 数据表），并对成品做整体质检。

## 1. 开工五问（缺一不动笔）

1. **给谁看**：受众是谁，他们已知道什么、关心什么、会为什么行动？
2. **要什么效果**：读完/看完后受众要记住什么、做什么（决策/购买/审批/传播）？
3. **载体与篇幅**：word 方案 / ppt 汇报 / 公众号 / 短视频脚本 / 海报？
4. **素材现状**：用户提供了什么（资料/数据/旧文案）？还缺什么（列清单）？
5. **口径与禁区**：数字口径、命名规范（品牌名写法）、不可出现的表述。

## 2. 结构设计（先骨架后血肉）

- 先产出**大纲 + 每部分的核心信息点**给用户确认，超过 3 页/800 字必须确认；
- 叙事骨架按用途选型：
  - 方案书：背景问题 → 目标 → 方案主体 → 实施计划 → 资源与风险；
  - 汇报材料：结论先行 → 关键数据 → 进展亮点 → 问题与请求 → 下一步；
  - 营销文案：痛点共鸣 → 方案价值 → 信任证据 → 行动号召；
  - 公众号：钩子开头 → 干货主体（分点/故事） → 金句收尾 → 引导互动。
- 标题准则：信息量 > 文采；"华东区 Q3 客户增长 40% 的三个动作"
  优于"砥砺前行，再创佳绩"。

## 3. 素材组织（调用对应技能）

| 需要 | 调用 |
|------|------|
| 数据、事实、案例、政策 | `office-research`（要求带来源） |
| 配图、图标、封面 | `office-image-search`（要求带授权） |
| 成稿为 Word 文档 | `office-word` |
| 成稿为 PPT 汇报 | `office-ppt` |
| 数据表格 | `office-excel` |
| 本地资料整理 | `office-computer` |

没有素材支撑的段落先写"【待补充：需要 XX 数据】"占位，终稿前与用户核对，
**绝不编造数据、案例、客户证言与政策条文**。

## 4. 写作与打磨

- 初稿一气呵成不加评判；打磨按"结构 → 事实 → 表达"三遍：
  1. 结构遍：每部分是否服务开篇定的目标？删与目标无关的段落；
  2. 事实遍：每个数字/专名/日期与来源核对；口径全文一致；
  3. 表达遍：删虚词（"的了吗呢"、副词堆叠），长句拆短句，
     每段一个核心句；正式文体与口语体不混用。
- 文风统一：全文人称、时态、语气一致；套用用户给的范文风格时说明对齐了哪些特征。
- 篇幅纪律：公众号正文 800–1500 字；方案书以"能删的都删了"为准；
  PPT 文案遵循 office-ppt 的每页要点规则。

## 5. 成品交付

- 默认产出**可编辑源文件**（docx/pptx/xlsx）+ 必要的 PDF 版；
- 文件命名 `主题_v1.docx`，改稿递增；多文件交付时给一张清单表
  （文件、用途、状态）；
- 交付语附一句修改指引："要改哪部分直接说，我会改对应脚本/段落重出"。

## 6. 交付前检查单

- [ ] 五问全部有答案，成品与"目标效果"对齐；
- [ ] 大纲经过用户确认；
- [ ] 所有数据/案例有来源或明确标注待补充；
- [ ] 文风、口径、命名全篇一致；
- [ ] 配图有授权结论；多文件已列清单；
- [ ] 没有编造的任何事实性内容。

## 相关技能

本技能是编排层：`office-research`（取数）、`office-image-search`（配图）、
`office-word` / `office-ppt` / `office-excel`（成稿）。
