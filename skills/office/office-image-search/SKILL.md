# 办公技能 · 搜图

## 1. 先问清三件事

1. **用途**：PPT 配图、文档插图、公众号封面还是壁纸？决定比例
   （16:9 / 4:3 / 竖版）与最小分辨率（PPT 全幅 ≥1280px 宽）。
2. **风格**：写实/扁平插画/线条/3D/暗色？给出 2–3 个参考关键词。
3. **版权要求**：商用还是内部使用？商用必须选明确可商用授权的图源
   （见下表），并在交付时标注来源与授权。

## 2. 图源优先级

| 场景 | 推荐来源 | 授权 |
|------|----------|------|
| 通用素材 | Unsplash、Pexels、Pixabay | 免费可商用 |
| 图标 | iconfont、Iconify、Feather/Material Icons | 按单个图标授权确认 |
| 插画 | unDraw、Open Peeps | 可商用（含改色） |
| 中国本土/电商 | 千图网等 | 注意会员授权范围 |
| 企业 Logo/产品图 | 官网/官方新闻稿 | 商标权仍归属企业，仅合理引用 |

检索技巧：在图源站内用"中文需求 → 英文关键词"翻译后搜索命中率更高；
组合词用"主体 + 风格 + 场景"（如 `factory worker flat illustration`）。

## 3. 标准工作流

1. **检索**：用 web_search 搜图源页面，或用 `office-browser` 打开图源站内搜索；
   每个需求给出 3–5 个候选缩略图链接让用户挑（不要只给一张就让用户接受）。
2. **下载**：下载原图到工作区 `图片素材_<主题>/` 目录，命名
   `主题_序号_来源.png|jpg`；禁止把缩略图当原图用。
3. **校验**（shell + Python/Pillow；Pillow 已随办公技能包预装，缺失才
   `pip install Pillow`）：
   ```bash
   python -c "from PIL import Image; im=Image.open('图.png'); print(im.size, im.mode)"
   ```
   检查：尺寸达标、非占位图、文件 > 20KB（太小的往往是损坏/占位）。
4. **交付**：列出清单表（文件名、尺寸、来源 URL、授权类型、建议用在哪一页），
   供 `office-ppt`/`office-word` 直接引用。

## 4. 使用纪律

- **版权红线**：搜索引擎图片页给出的图 ≠ 可用图；必须落到具体授权页确认。
  商用场景拿不准授权时，明确告诉用户"此图仅限内部预览"。
- **人脸与商标**：含可识别人脸的图商用需肖像授权；Logo 仅用于指代性引用。
- **数量克制**：PPT 配图每页 1 张主视觉即可；文档插图服务论点，不为装饰而插图。
- **统一风格**：同一份材料里的插图风格必须一致（要么全是照片，要么全是同套插画），
  不混搭。

## 5. 交付前检查单

- [ ] 每张图有来源 URL 与授权结论；
- [ ] 尺寸/比例符合用途，无模糊拉伸；
- [ ] 已给出候选供用户选择，而非单张强制；
- [ ] 全套图片风格统一；
- [ ] 文件已落盘且可打开（Pillow 校验通过）。

## 相关技能

- `office-ppt` / `office-word`：图的最终去处，注意其版式规则；
- `office-browser`：需要登录或交互式筛选的图源站；
- `office-research`：需要确认图片版权信息出处时。
