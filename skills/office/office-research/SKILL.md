# 办公技能 · 查资料

## 1. 核心方法：检索 → 交叉验证 → 标注出处

- **单一来源不采信**：关键事实（数字、日期、政策条款、报价）至少两个独立来源
  相互印证；两个来源说法冲突时如实呈现分歧，不擅自裁决。
- **溯源到一手来源**：新闻稿 → 找到原始公告；统计数字 → 找到原始报告/统计局；
  转载链越短越可信。优先级：官方公告/监管网站 > 一手媒体/行业年报 >
  二手汇编 > 自媒体/论坛。
- **时效性**：默认只要近 24 个月的信息；政策类必须确认"现行有效"，
  注明发布与生效日期。查不到新数据时明确说"最新可得为 X 年数据"。

## 2. 工具分工

| 工具 | 用途 |
|------|------|
| `web_search` | 关键词检索、找入口、快问快答 |
| `web_fetch` | 抓取具体页面的完整内容 |
| `office-browser` | 需要交互（登录、翻页、动态加载）的站点 |
| shell + Python | 结果整理、批量抓取、生成摘要表 |

## 3. 标准工作流

1. **拆解问题**：把用户的任务拆成 3–7 个可独立检索的子问题
   （"XX 行业是否值得进入"→ 市场规模/增速/主要玩家/政策/成本结构/风险）。
   与用户确认拆解结果再大规模检索。
2. **检索执行**：每个子问题 2–3 组不同关键词（中文 + 英文 + 行话同义词）；
   记录每个命中的 URL、标题、要点、日期。
3. **交叉验证**：关键数字做两源核对；找不到第二来源的结论标注"单一来源"。
4. **结构化整理**：产出按子问题组织的资料卡：
   每条 = 结论一句 + 支撑数据 + 来源 URL + 日期 + 可信度（高/中/低）。
5. **输出结论**：给出"已确认 / 存疑 / 未找到"三类清单，绝不用编造填充空缺。

## 4. 检索技巧

- 限定站点：`关键词 site:gov.cn`（政策）、`site:stats.gov.cn`（统计）；
  加引号精确匹配；用 `filetype:pdf` 找报告原文。
- 中文资料不足时换英文关键词再查一轮（国际市场、技术类资料尤其如此）。
- 付费墙/登录墙内容不要硬绕；说明"该报告需付费，此处仅摘要页信息"。
- 抓不到的页面换缓存/镜像思路前，先换关键词重搜，通常有等效公开来源。

## 5. 诚信红线

- **查不到就说查不到**："未找到公开数据"是合法且常见的结论；
  编造数字、编造来源、"据公开资料显示"式含糊引用一律禁止。
- **区分事实与观点**：整理时给观点标注主体（"某券商认为…"），
  不把预测当事实、把宣传口径当中立数据。
- **付费/内部资料**：用户上传的内部资料只在其授权范围内使用，不外传。

## 6. 交付前检查单

- [ ] 每个关键结论都有可点击的来源 URL 与日期；
- [ ] 关键数字经过两源核对或已标注单一来源；
- [ ] 政策/时效类信息确认了现行有效；
- [ ] 输出区分了"事实 / 观点 / 未找到"；
- [ ] 资料已结构化（表格或分点），可直接被 office-word/office-ppt 引用。
