# 办公技能 · PPT 制作

一条原则：**不做"白底加要点"的流水线幻灯片**。每页都要有一个具体的论点或信息焦点
（数字、结论、图示），而不是一个话题标签加一排形容词。

## 1. 动手前先定三件事

1. **受众与场合**：给谁看、讲多久、在什么场合投影。10 分钟汇报不超过 8 页正文。
2. **信息主线**：用一句话写出"听众听完要记住的结论"，每页标题直接服务这条结论
   （标题写结论句，不写"背景介绍"这类栏目词）。
3. **配色三角色**：`背景 → 主色 → 强调色`。
   - 背景承担 60–70% 视觉面积（米白/暖灰/深蓝/近黑）；
   - 主色取自主题本身（企业 VI、行业色、品牌 Logo），用于标题、图表、结构元素；
   - 强调色只用**一种**高饱和色，占 5–10%，给全片最重要的那个数字或结论。
   - 在脚本顶部定义一次常量（`BG/PRIMARY/ACCENT/TEXT/MUTED`），全程只引用常量，
     逐页临时挑色是版面混乱的头号来源。
   - 深浅"三明治"结构：封面与结尾用深色底，内容页用浅色底。

## 2. 环境自检（办公版已预装，直接用）

办公技能包依赖（python-pptx 等）已由启动器预装到项目运行环境，**不要在对话中
重复安装**；仅当 import 报缺失时才补装（只报告一次，不要反复重试）：

```bash
python -c "import pptx; print(pptx.__version__)"   # 预装缺失时: pip install python-pptx
soffice --version        # 可选：导出 PDF 需要 LibreOffice
python -m markitdown --help   # 可选：提取既有 PPT 文本
```

- 首选 **python-pptx** 建稿/改稿（纯 Python，运行时最容易就位）。
- 若运行时技能池中已有内置 `pptx` 技能且其依赖（markitdown/pptxgenjs 等）可用，
  可按其流程执行；依赖不满足时以本技能的 python-pptx 路线为准。

## 3. 每页版式规则

- 每页**必须有一个视觉元素**：图表、图示、大数字、图片或色块结构；纯文字页一律重做。
- 每页**只有一个视觉焦点**，其余元素做从属：超大数字、单张大图、一句加粗断言。
- 分组靠对齐与间距，不靠画框：细分隔线、行式列表、极浅色横带都可以；
  禁用"左侧色条/顶部彩条"式装饰——那是模板味最重的元素。
- 中文字体优先使用本机可用字体（思源黑体/微软雅黑/苹方），字号下限：正文 18pt、
  注释 12pt；一页正文不超过 8 行要点，每个要点不超过 20 字，写关键词不写整句。
- 图表优先用表格数据生成的原生图表（pptx chart），坐标轴与图例文字 ≥12pt。

## 4. 标准工作流

1. **输入盘点**：用户给了主题、资料文件还是旧 PPT？读不到的信息先问清，不要编造数据。
2. **大纲先行**：先输出"每页标题 + 该页焦点"的大纲给用户确认（超过 10 页必须确认）。
3. **脚本生成**：写一个可重复执行的 Python 脚本生成 .pptx（不要手改二进制文件），
   脚本内配色/字体用常量；用户后续改需求时改脚本重跑。
4. **视觉自检**：无 LibreOffice 时，用 python-pptx 复查每页元素边界
   （不越界、不重叠、文本框不溢出）；有 LibreOffice 时导出 PDF 再转逐页 PNG，
   用看图工具逐页检查。
5. **交付**：输出文件放在当前工作区会话文件目录，命名带版本：
   `主题_v1.pptx`；改稿产出 `主题_v2.pptx`，不覆盖用户原件。

## 5. 编辑既有 PPT

- 用户原件**只读**：先复制为 `<原名>_backup.pptx` 再改副本；仅当用户明确要求原地修改时例外。
- 提取结构：`python -m markitdown 原件.pptx`（不可用时用 python-pptx 遍历
  `slide.shapes` 文本）。
- 批量改字体/配色/Logo 时写脚本遍历处理并汇报每页改动数，不要逐页手工试。

## 6. 交付前检查单

- [ ] 每页标题是一句结论，不是栏目名；
- [ ] 全片只出现背景/主色/强调色三角色，没有游离颜色；
- [ ] 没有纯文字页，没有装饰色条；
- [ ] 数据与事实均来自用户资料，未虚构数字（查数据配合 `office-research` 技能）；
- [ ] 需要配图的页面已用 `office-image-search` 检索并确认可用性；
- [ ] 输出文件在工作区可被用户找到，并附一句"改哪页告诉我，我改脚本重出"。
