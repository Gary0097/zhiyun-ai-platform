# 办公技能 · Excel 表格

## 1. 环境自检（办公版已预装，直接用）

openpyxl / pandas 已由启动器预装，不要在对话中重复安装；仅 import 报缺失时才补装：

```bash
python -c "import openpyxl; print(openpyxl.__version__)"   # 缺失时: pip install openpyxl
python -c "import pandas; print(pandas.__version__)"       # 预装自带；缺失时: pip install pandas
soffice --version    # 可选：重算公式/导 PDF 需要 LibreOffice
```

- 读写 .xlsx 首选 **openpyxl**；CSV/TSV 直接用标准库或 pandas。
- .xls 老格式先转 .xlsx（LibreOffice `--convert-to xlsx`）再处理。

## 2. 数据安全铁律

- **用户表格原件只读**。任何修改先复制副本：`<原名>_工作副本.xlsx`；
  交付成品另存 `主题_v1.xlsx`。绝不在原件上直接改。
- 修改前先记录行列数与关键单元格值，改动后核对总数一致或解释差异来源。
- 合并/去重/删除行之前，先向用户展示将被影响的具体行样例再执行。

## 3. 标准工作流

### 读取与勘察

1. 先看结构再碰数据：工作表清单、行列数、表头行位置、合并单元格、明显空区。
2. 提取样本（前 10 行）确认列含义；表头不在第一行时先定位。
3. 对脏数据先出"体检报告"：空值列、重复行、类型混乱列、异常值，让用户决策怎么处理。

### 新建表格

1. **结构先行**：明确这是登记表（一行一条记录）、报表（分层汇总）还是看板（图表为主）。
2. 表格规范：
   - 表头唯一且不合并；一列一种类型；日期用真日期格式，不要文本日期；
   - 需要计算的一律用**公式**（SUMIFS/COUNTIFS/VLOOKUP 或新函数），不写死数值，
     这样用户改数后结果自动更新；
   - 大表套用表格样式并冻结首行；打印需求时设置打印区域与重复标题行。
3. 图表：数据在同一表或引用清晰的独立表；图表标题写结论（如"华东占 62%"，
   不是"销售额图表"）。

### 清洗与转换

- 流程写成可重跑的 Python 脚本：读入 → 每步清洗函数 → 输出新文件；
  每步打印前后行数，让用户可核对。
- CSV 乱码：中文优先按 GBK/GB18030 重读；输出统一 UTF-8 with BOM（Excel 直接打开不乱码）。
- 多表合并以"键列 + 来源列"方式进行，保留来源标记便于追溯。

## 4. 公式与重算注意

- openpyxl 写入公式后不会计算值；没有 LibreOffice 重算时，单元格显示为空或 0，
  属正常现象——交付时说明"首次在 Excel/WPS 打开后自动计算"，
  或用 LibreOffice `--convert-to xlsx` 重算一遍。
- 公式引用区域随数据行数变化时，用整列引用或命名区域，避免追加数据后漏行。

## 5. 交付前检查单

- [ ] 原件未被改动，成品为新文件；
- [ ] 数字能对上：汇总 = 明细之和（或说明差异）；
- [ ] 没有文本型数字/日期导致排序错乱；
- [ ] 列宽合适、无 ##### 溢出、冻结窗格生效；
- [ ] 公式版本说明已告知（是否需要打开时重算）；
- [ ] 大于 1 万行的操作说明性能影响，复杂分析先抽样验证再全量跑。
