## 七、可复用 SQL

```sql
SELECT * FROM v_replenishment_advice;      -- 建议量/ROP/耗尽日/建议下单日
SELECT * FROM v_inventory_alert ORDER BY 可用天数;   -- 6 条预警（4 紧急）
SELECT r.* FROM v_supplier_recommendation r JOIN v_inventory_alert a
  ON a.物料名称=r.物料名称 ORDER BY r.物料名称, r.排名;   -- TOP3 + 价格校验标注
SELECT * FROM v_candidate_pool_all WHERE 物料名称 LIKE '%钣金%';  -- 9 家全未达标
SELECT * FROM calc_params;                 -- snapshot_at / 阈值 / 权重
SELECT 类型, COUNT(DISTINCT 物料编号) SKU数, COUNT(*) 笔数, SUM(数量) 总量
  FROM inventory_txn WHERE 日期='2026-09-17' GROUP BY 类型;   -- 217 / 42
SELECT COUNT(*) 总SKU, SUM(当前库存<安全库存阈值) 低于安全库存,
       SUM(预警状态='紧急') 紧急 FROM inventory_snapshot;      -- 12 | 6 | 4
```

`v_inventory_alert` 视图定义：`SELECT ... , 安全库存阈值-当前库存 AS 缺口数量, 可用天数, 采用日均消耗, 预警状态 FROM inventory_snapshot WHERE 当前库存 < 安全库存阈值`（基表 JOIN `material_master` 复算结果与视图完全一致）。

补货口径：ROP = 日均消耗 × 采购提前期 + 安全库存阈值；建议量 = ⌈(ROP − 当前库存 − 在途)/包装批量⌉ × 包装批量，且不低于 MOQ；若 库存+在途 ≥ ROP → 建议量 0。出处：知识库《金汉隆-智能采购 / 业务口径_供应商评估与补货.md》。
