# 供应商推荐三重门控（评分权重、准入门槛、价格校验触发条件）

## Trigger

需要为某待补货物料选定推荐供应商，或需要把"为什么推荐它 / 为什么要压价"写成可复核结论时。

## Pre-conditions / inputs

- `calc_params` 提供评分权重与阈值（权重未校准）。
- 候选池逐家数据：准时率、合格率、均价、近 180 天批次数（`v_candidate_pool_all`、`v_supplier_recommendation`）。
- 建议量已算出：见 [[digest/procedure/replenishment-advice-calculation-runbook.md|补货建议量计算 runbook]]（其步骤 8 关联本门控，其步骤 7 的 MOQ/批量是本门控量化节省的乘数）。

## Steps（三道门按序过，任一不过就改变结论）

1. 算综合评分 = 0.45×准时率 + 0.35×合格率 + 0.20×价格竞争力；仅作排序依据，不当绝对优劣。
2. 过准入门槛：准时率 ≥ 0.70 **且** 合格率 ≥ 0.965；未达线者不得进入推荐位，即使评分更高。
3. 若该品类合格候选数 = 0 → 不编造推荐，转人工，并写清"卡在哪一项、差多少个百分点"；动作＝人工特批最优者 + 加严来料检验 + 启动新供应商开发（M09 钣金 9 家全不达标，最优 S018 合格率 0.9107，差 5.43pp）。
4. 过价格校验：主荐价 > 池内最低价 × 1.1 **且** 与更低价供应商评分差 ≤ 0.05 → 触发比价提示。
5. 触发后并列给出两个动作：①压价目标价直接取 最低价×1.1（M03：281.83×1.1 = 310.01；M07：189.38×1.1 = 208.32）；②改选更低价供应商并量化节省（M03 改 S030 287.19 元，160 件省 8,227 元）。
6. 输出逐项标注：评分、门槛通过情况、价格校验结论、样本批次数、备选货源。

## Failure modes / caveats

- 评分是"交期紧迫度"取向且未校准：近 180 天仅 1 批的薄样本可拿满分（M01 S015 = 1.0000），需小批验证或与备选分单。
- 只按评分排序会把不达标供应商推上推荐位：门槛是硬约束，先过滤后排序。
- 换更低价供应商的前提是评分差 ≤ 0.05（M03 差 0.0495 才成立）；超阈值则只走压价动作，不换人。
- 池内更贵的候选直接排除，不进比价提示（M07 的 S040 236.69 元）。
- 阈值全部来自 `calc_params`，换快照日或改权重后须重读，不可沿用历史数字。
