## 复用的业务口径（来自知识库《业务口径_供应商评估与补货.md》）
- **ROP** = 日均消耗 × 采购提前期 + 安全库存阈值
- **建议补货量** = ⌈(ROP − 库存 − 在途) / 包装批量⌉ × 包装批量，不低于 MOQ；若 库存+在途 ≥ ROP 则为 0
- **综合评分** = 0.45×准时率 + 0.35×合格率 + 0.20×价格竞争力
- **供应商准入线**：准时率 ≥ 0.70、合格率 ≥ 96.5%（近180天）
- **价格校验**：TOP1 价格若 > 池内最低价×1.1 且与第2名评分差 ≤ 0.05 → 校验不通过，改荐次选
- 可用天数/紧迫度属"交期紧迫度评分，**未校准**"，仅用于排序
- 到货单号格式 `AR+后缀-批次`；承诺到货日期 = 采购日期 + 提前期；在途数量 = 未到批次数量
- ⚠️ 看真实节点不要信 `purchase_orders.状态`（滞后），以 `arrival_records.状态` + `quality_inspections.判定` 为准
