# 人事工资核算技能

中秋/月末算工资就用它。处理流程：

1. **拿到数据**：用户会给考勤表/薪资标准（CSV、Excel 另存 CSV、或直接粘贴的表格文本均可）。若给的是粘贴文本，先存成临时 CSV（表头用中文名）。
2. **执行计算**（以本 SKILL.md 所在目录为根，定位 `payroll/scripts/payroll.py`）：

```bash
python3 <skill目录>/scripts/payroll.py 输入.csv --out 工资表_2026-09.csv
# 可选参数：
#   --hf 5              公积金个人比例%（默认5）
#   --rates 0.08,0.02,0.002   社保个人比例：养老,医疗,失业
```

3. **表头别名**（自动识别）：姓名/基本工资(底薪)/岗位工资/出勤天数/应出勤天数/加班_工作日/加班_周末/加班_法定(小时)/迟到扣款/社保基数/公积金基数/专项附加扣除/其他加项/其他扣款/中秋福利(节日福利)。缺列按默认处理（应出勤21.75、社保基数=基本工资）。
4. **输出**：终端打印每人明细与汇总；`--out` 生成 CSV 工资表（UTF-8 BOM，Excel 直接打开），把文件路径告诉用户。

## 计算口径（向用户解释时使用）

- 时薪 = 基本工资 ÷ 21.75 ÷ 8；加班费 = 时薪 ×（工作日×1.5 + 周末×2 + 法定假日×3）
- 缺勤扣款 = 基本工资 ÷ 应出勤天数 × 缺勤天数
- 社保个人 ≈ 基数 × 10.2%（养老8%+医疗2%+失业0.2%，可按当地调整 --rates）
- 个税 =（应发 − 社保个人 − 公积金个人 − 5000 − 专项附加扣除）× 税率 − 速算扣除（月度表）
- 实发 = 应发 − 社保个人 − 公积金个人 − 个税 − 其他扣款

## 注意

- 数字变化务必以脚本输出为准，不要口算。
- 用户只给部分人/部分列也能算，先说明缺省口径再执行。
- 汇总行（人数、应发、实发合计）在输出第一行，回复时突出展示。
