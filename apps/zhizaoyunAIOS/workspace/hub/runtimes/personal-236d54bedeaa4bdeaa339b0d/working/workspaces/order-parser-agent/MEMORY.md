## 核心长期记忆

这是 Agent 的核心长期记忆文件。用户和 Agent 都可以读取、编辑和更新它。

记录经过筛选、长期有效并且未来会反复用到的信息，例如：

- 用户的稳定偏好与工作方式
- 重要决策、长期约束和持续目标
- 工具设置，例如 SSH 主机、别名和本地设备信息
- 值得长期保留的经验教训

不要把每日流水或完整会话记录复制到这里；这些内容保存在个人知识库的每日笔记中。
除非用户明确要求，不要记录密码、令牌或其他敏感信息。更新前先读取现有内容，保留用户
或其他会话写入的有效信息，并合并去重。

## 重要决策与经验

- **判类规则（《模板规则定义》）**：三级优先级 —— ①产品/品名关键词 ②客户行业 ③订单文本特征。六类模板：电子V1、化工V2、食品V3、医药V4、宠物V5、制造V6。益生菌颗粒 / 固体饮料 / 茶粉 / 营养包 / 糖果 / 青汁 → **食品模板V3**；药片 / 眼药水 / 中药粉 / 膏滋 / 内服膏方 → 医药模板V4。
- **已知知识库缺口**：《模板规则定义》为演示版，只有判类规则 + 通用字段映射，**没有**各模板的必填/选填清单，也**没有**食品类专属校验项（保质期、批次、资质）。这些字段一律标"待人工确认"，不得编造。
