## 核心长期记忆

这是 Agent 的核心长期记忆文件。用户和 Agent 都可以读取、编辑和更新它。

记录经过筛选、长期有效并且未来会反复用到的信息，例如：

- 用户的稳定偏好与工作方式
- 重要决策、长期约束和持续目标
- 工具设置，例如 SSH 主机、别名和本地设备信息
- 值得长期保留的经验教训

不要把每日流水或完整会话记录复制到这里；这些内容保存在个人知识库的每日笔记中。
除非用户明确要求，不要记录密码、令牌或其他敏感信息。更新前先读取现有内容，保留用户
或其他会话写入的有效信息，并合并去重。

## 重要决策与经验

- **判类规则（《模板规则定义》）**：三级优先级 ①产品/品名关键词 ②客户行业 ③订单文本特征。六类模板：电子V1、化工V2、食品V3、医药V4、宠物V5、制造V6。
- **通用字段映射**（所有模板共用，演示版无模板专属必填清单）：客户名称→客户名称；提取品名→机器产品名称/包装产品（标准化）；提取数量→数量（数字+单位规范化）；提取交期→承诺交期（YYYY-MM-DD）；模板分类（判类后写入）；SO/MO 编号系统生成。专属字段一律标"待人工确认"，不得编造。
- **已知歧义**："配件"同时命中电子V1（配件/连接器配件）与制造V6（包装机配件），规则无显式消歧算法，需查客户档案行业；客户档案不在知识库中（2026-09-17 江苏合昌逸品案例确认）。
